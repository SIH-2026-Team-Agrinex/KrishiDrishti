1. STEP 1: SET UP FREE POSTGRESQL DATABASE
================================================================================

Neon provides serverless PostgreSQL with 0.5 GB storage, automatic scaling,
and instant connection pooling at zero cost.

1. Go to https://neon.tech and sign up with your GitHub account.
2. Create a new project:
   - Project Name: `<your-database-name>`
   - Region: Select nearest region to your target audience.
   - Click "Create Project".

3. Get your Connection String:
   - On your database dashboard, locate the connection details.
   - Ensure the connection type is set to **"Pooled connection"** (recommended for web services).
   - Copy the URI string. It follows this format:
     postgresql://<db_user>:<db_password>@<db_host>/<db_name>?sslmode=require

4. Create the `crop_reports` table:
   - In the database console, open the **"SQL Editor"**.
   - Paste this SQL query and click **"Run"**:

   CREATE TABLE IF NOT EXISTS crop_reports (
       id VARCHAR(64) PRIMARY KEY,
       created_at TIMESTAMPTZ DEFAULT NOW(),
       crop_identified VARCHAR(100),
       condition_or_pest VARCHAR(150),
       issue_type VARCHAR(50),
       confidence FLOAT,
       risk_level VARCHAR(50),
       location_name VARCHAR(150),
       latitude FLOAT,
       longitude FLOAT,
       raw_json TEXT NOT NULL
   );

5. Local Environment (Optional):
   You can add this connection string to your local `AgrineX_models/.env`:
   DATABASE_URL="<your_database_connection_uri>"

2. STEP 2: REPOSITORY ON GITHUB
================================================================================

Ensure your codebase is pushed to your private or public GitHub repository:
Repository: https://github.com/<your-username>/<your-repo-name>
Branch: main

All secret `.env` files, temporary snapshots, and node_modules must remain

3. STEP 3: DEPLOY BACKEND API SERVICE
================================================================================

1. Go to https://render.com and sign in with GitHub.
2. Click **"New +"** -> **"Web Service"**.
3. Choose **"Build and deploy from a Git repository"** and select your repository.
4. Fill in the service configuration:
   - **Name**: `<your-backend-service-name>`
   - **Region**: Nearest region
   - **Branch**: `main`
   - **Root Directory**: `AgrineX_models`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn api_server:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Select **"Free"** ($0/month)

5. Add Environment Variables (click "Advanced" -> "Add Environment Variable"):
   - Key: `GROQ_API_KEY`
     Value: `<your_llm_api_key_here>`
   - Key: `DATABASE_URL`
     Value: `<your_database_connection_uri>`
   - Key: `ALLOWED_ORIGINS`
     Value: `*`
   - Key: `PYTHON_VERSION`
     Value: `3.10.12`

6. Click **"Deploy Web Service"**.
   Render will install dependencies, load the vision models, and start the API.
   Once deployed, Render provides a public HTTPS URL:
   `https://<your-backend-service-name>.onrender.com`

   Verify by opening:
   - `https://<your-backend-service-name>.onrender.com/health` (shows status: "online")
   - `https://<your-backend-service-name>.onrender.com/docs` (interactive API documentation)

================================================================================
4. STEP 4: DEPLOY FRONTEND ON VERCEL
================================================================================

1. Go to https://vercel.com and log in with GitHub.
2. Click **"Add New..."** -> **"Project"**.
3. Select your repository.
4. Configure Project Settings:
   - **Framework Preset**: Vite
   - **Root Directory**: Click "Edit" and select `frontend`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`

5. Add Environment Variables (click the Environment Variables dropdown):
   - Key: `VITE_USE_LOCAL_DB`
     Value: `false`
   - Key: `VITE_API_BASE_URL`
     Value: `https://<your-backend-service-name>.onrender.com/api`
   - Key: `VITE_GROQ_API_KEY`
     Value: `<your_llm_api_key_here>`
   - Key: `VITE_ENABLE_LIVE_OPEN_METEO_FALLBACK`
     Value: `true`

6. Click **"Deploy"**.
   Your frontend will be compiled and deployed with a secure SSL URL:
   `https://<your-app-name>.vercel.app`

5. STEP 5: TEST AND VERIFY LIVE PRODUCTION SYSTEM
================================================================================

1. Open your live deployment URL on mobile or desktop.
2. The browser grants Camera permissions securely over HTTPS.
3. Snap or upload a crop leaf image:

All components are live, resilient, and fully secured without exposed keys!
